# Analog Archive – CSS 3D Clickable Flip Cards

A flip-card page promoting a collection of six classic analog cameras. Click (or press Enter/Space on) a card to flip it and read the story behind the camera.

## Structure
- `index.html` – main page with the six flip cards
- `article.html` – article page
- `scss/style.scss` – SCSS source
- `css/style.css` – compiled CSS used by the pages
- `js/script.js` – toggles the `is-flipped` class on click

## What I changed from the sample
- New product theme (analog cameras) with my own colours and typography
- Cameras drawn with pure CSS
- Keyboard-accessible cards (buttons with `aria-pressed`)
- Responsive grid: 3 / 2 / 1 columns
